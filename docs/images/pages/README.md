# WebUI page screenshots

Keep each page screenshot at the fixed filename below. `repo/README.md` links to
these relative paths, so screenshots can be refreshed by replacing the image
file without changing the README.

| Page | Route | Filename |
| --- | --- | --- |
| Dashboard | `/` | `dashboard.png` |
| Task Manager | `/tasks` | `task-manager.png` |
| Settings | `/settings` | `settings.png` |
| Maintain Adapters | `/agent` | `agent-maintenance.png` |
| Adapter Lab | `/adapter-lab` | `adapter-lab.png` |

Use the same browser viewport width, interface language, and PNG format for all
screenshots when possible. For long pages, capture the view that best represents
the primary features instead of shrinking the text to include every section.
